# 🍰 Тёплая крошка — сайт домашней кондитерской

Адаптивный сайт интернет-магазина для продажи выпечки, пирожных и десертов. Проект выполнен в стиле **Skeuomorphism (скевоморфизм)** с использованием тёплой цветовой палитры, текстур бумаги, объёмных кнопок и реалистичных визуальных материалов.

## 📌 О проекте

«Тёплая крошка» — демонстрационный сайт кондитерской, позволяющий покупателям знакомиться с ассортиментом десертов, сортировать товары, добавлять их в корзину и просматривать стоимость заказа.

## 🎨 Дизайн

Основные особенности оформления:

- Кремовые, карамельные и бордовые оттенки.
- Текстурированные поверхности, имитирующие бумагу.
- Кнопки с эффектом лакированного покрытия.
- Градиенты и внутренние блики.
- Декоративные рамки и тонкие границы.
- Элегантная типографика с использованием шрифтов с засечками.
- Умеренное использование теней и скруглений.

## 🛠 Используемые технологии

- **HTML5** — структура сайта.
- **CSS3** — оформление, анимации и адаптивная вёрстка.
- **JavaScript** — интерактивность и логика корзины.
- **Unsplash** — фотографии десертов.

Проект не требует установки дополнительных библиотек или фреймворков.

## ✨ Функциональные возможности

### 1. Главная страница
- Логотип и навигационное меню.
- Приветственный блок.
- Кнопка перехода к каталогу.
- Информация о преимуществах кондитерской.

### 2. Каталог продукции
- Карточки товаров с фотографиями.
- Названия и описания десертов.
- Цены в узбекских сумах.
- Кнопки добавления в корзину.

### 3. Фильтрация и сортировка
- Фильтрация по категориям.
- Сортировка по возрастанию цены.
- Сортировка по убыванию цены.
- Сортировка по названию.

### 4. Корзина
- Добавление товаров.
- Увеличение и уменьшение количества.
- Удаление товаров при уменьшении количества до нуля.
- Автоматический подсчёт общей стоимости.
- Отображение количества товаров.

### 5. Дополнительные разделы
- О кондитерской.
- Часто задаваемые вопросы (FAQ).
- Подписка на новости.
- Контактная информация и подвал сайта.

## 📱 Адаптивность

Сайт адаптирован для:
- Настольных компьютеров.
- Ноутбуков.
- Планшетов.
- Смартфонов.

Используются CSS Media Queries для изменения расположения элементов в зависимости от ширины экрана.

## 🚀 Как запустить проект

1. Скачайте файл `teplaya_kroshka.html`.
2. Сохраните его в отдельную папку.
3. Найдите файл на компьютере.
4. Откройте его двойным щелчком.
5. Сайт запустится в браузере.

Установка дополнительных программ не требуется.
